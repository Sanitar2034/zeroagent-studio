# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| `main` branch | Yes |
| Older tags / forks | Best effort |

## Reporting a vulnerability

**Do not** file public GitHub issues for security vulnerabilities.

Contact [@sakurablush](https://github.com/sakurablush) privately with:

1. Description of the issue and potential impact
2. Steps to reproduce
3. Affected version or commit
4. Suggested remediation (optional)

We aim to respond within **72 hours**. Critical issues affecting API key handling,
sandbox escape, or unintended data exfiltration are prioritized.

Full security model: [docs/SECURITY.md](docs/SECURITY.md). Per-tool safety: [docs/TOOL-SAFETY.md](docs/TOOL-SAFETY.md).
